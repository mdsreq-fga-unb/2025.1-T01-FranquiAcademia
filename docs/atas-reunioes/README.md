# Atas de Reuniões - Evidências de Execução dos Processos ESW e ER

Este diretório contém as atas das reuniões realizadas com o Product Owner (Luigi) para demonstrar a aplicação dos processos de Engenharia de Software (ESW) e Engenharia de Requisitos (ER).

## Índice das Atas

### 1. [Ata da Reunião - Kickoff do Projeto](./ata-reuniao-01-kickoff.md)
**Data:** 15/01/2025  
**Foco:** Definição inicial do projeto e alinhamento sobre visão, objetivos e escopo.

**Processos ESW/ER Demonstrados:**
- Elicitação de Requisitos (entrevista estruturada)
- Análise e Priorização de Requisitos
- Especificação inicial em User Stories
- Definição da metodologia ágil (Scrum)
- Arquitetura inicial do sistema

### 2. [Ata da Reunião - Refinamento do Backlog](./ata-reuniao-02-refinamento-backlog.md)
**Data:** 22/01/2025  
**Foco:** Refinamento do Product Backlog e detalhamento das User Stories para o Sprint 1.

**Processos ESW/ER Demonstrados:**
- Refinamento de Requisitos (workshop)
- Detalhamento de User Stories com critérios de aceitação
- Análise de Requisitos Não Funcionais
- Sprint Planning
- Definição da arquitetura técnica detalhada

### 3. [Ata da Reunião - Sprint Review e Retrospectiva](./ata-reuniao-03-sprint-review.md)
**Data:** 05/02/2025  
**Foco:** Apresentação das funcionalidades desenvolvidas no Sprint 1 e retrospectiva do processo.

**Processos ESW/ER Demonstrados:**
- Validação de Requisitos Implementados
- Identificação de novos requisitos
- Refinamento de requisitos existentes
- Sprint Review com métricas
- Retrospectiva e melhoria contínua
- Sprint Planning para próximo sprint

### 4. [Ata da Reunião - Refinamento Final e Preparação para Entrega](./ata-reuniao-04-refinamento-final.md)
**Data:** 12/02/2025  
**Foco:** Refinamento final dos requisitos, validação das funcionalidades e preparação para entrega.

**Processos ESW/ER Demonstrados:**
- Validação final de todos os requisitos
- Verificação de requisitos não funcionais
- Especificação final de requisitos
- Sprint Review final com métricas completas
- Validação final com PO
- Preparação para entrega

## Evidências de Processos Demonstradas

### Engenharia de Requisitos (ER)
✅ **Elicitação de Requisitos**
- Entrevistas estruturadas com PO
- Workshops de refinamento
- Análise de necessidades dos stakeholders

✅ **Análise de Requisitos**
- Priorização (MoSCoW)
- Validação contínua
- Refinamento iterativo

✅ **Especificação de Requisitos**
- User Stories com critérios de aceitação
- Requisitos funcionais e não funcionais
- Documentação estruturada

✅ **Validação de Requisitos**
- Demonstrações para PO
- Feedback contínuo
- Aprovação formal

### Engenharia de Software (ESW)
✅ **Metodologia Ágil**
- Scrum com sprints de 2 semanas
- Cerimônias regulares (Planning, Review, Retrospective)
- Product Backlog gerenciado

✅ **Desenvolvimento Iterativo**
- Ciclos de desenvolvimento com feedback
- Melhoria contínua baseada em retrospectivas
- Adaptação baseada em métricas

✅ **Qualidade de Software**
- Testes automatizados (85-98% cobertura)
- Code review
- Definição de Pronto (DoD)

✅ **Arquitetura e Tecnologias**
- Arquitetura modular e escalável
- Stack tecnológico moderno
- DevOps e CI/CD

## Conclusão

As atas demonstram a aplicação sistemática dos processos de Engenharia de Requisitos e Engenharia de Software ao longo de todo o ciclo de desenvolvimento, desde a elicitação inicial até a entrega final do produto, com evidências claras de:

- Comunicação contínua com stakeholders
- Validação e refinamento de requisitos
- Desenvolvimento iterativo e incremental
- Controle de qualidade
- Melhoria contínua do processo
