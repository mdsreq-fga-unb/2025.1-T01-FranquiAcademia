# Processos de Engenharia de Software e Engenharia de Requisitos

## Metodologia Adotada

### Engenharia de Requisitos (ER)
- **Elicitação de Requisitos**: Entrevistas com stakeholders, análise de documentos, workshops
- **Análise de Requisitos**: Validação, priorização e refinamento dos requisitos
- **Especificação de Requisitos**: Documentação em formato de User Stories
- **Validação de Requisitos**: Revisão com PO e stakeholders

### Engenharia de Software (ESW)
- **Metodologia Ágil**: Scrum com sprints de 2 semanas
- **Desenvolvimento Iterativo**: Ciclos de desenvolvimento com feedback contínuo
- **Testes**: TDD (Test-Driven Development) e testes de aceitação
- **Integração Contínua**: Deploy automático e revisão de código

## Artefatos Produzidos
- User Stories com critérios de aceitação
- Protótipos de interface
- Documentação técnica
- Evidências de reuniões e decisões

## Ferramentas Utilizadas
- GitHub para versionamento
- Teams para reuniões
- Figma para prototipagem
- Jira/Trello para gestão de backlog
