# DeltaCore - Sistema de Gestão Inteligente

## 📋 Descrição

O **DeltaCore** é um sistema completo de gestão desenvolvido especificamente para academias que operam com modelo de franquias e sistema de créditos por aula. A plataforma oferece funcionalidades avançadas de análise de dados, automação de comunicação e gestão inteligente de alunos.

## 🎯 Objetivos do Produto

- **Análise de Dados**: Cruzamento e apresentação de informações relevantes sobre clientes, academia e funcionários
- **Automação de Comunicação**: Envio automatizado de mensagens personalizadas para diferentes segmentos de clientes
- **Gestão de Usuários**: Controle completo de usuários, créditos e histórico de visitas
- **Visualização de Agendamentos**: Interface intuitiva para visualização da agenda dos studios

## ✨ Características Principais

### 🚀 Automação Inteligente
- Mensagens automáticas de boas-vindas
- Lembretes de aula personalizados
- Campanhas de recuperação de alunos inativos
- Comunicação segmentada por perfil de cliente

### 📊 Dashboard Analítico
- Relatórios em tempo real
- Métricas de performance da franquia
- Indicadores de engajamento
- Filtros personalizáveis por período

### 👥 Gestão de Alunos
- Controle de créditos por modalidade
- Histórico completo de participação
- Segmentação por status (ativo, inativo, pós-experimental)
- Análise de comportamento e preferências

### 📅 Sistema de Agendamentos
- Visualização da agenda dos studios
- Controle de horários e instrutores
- Gestão de capacidade por aula
- Integração com sistema de créditos

## 🛠️ Tecnologias Utilizadas

### Frontend
- **React** com Vite
- **Tailwind CSS** para estilização
- **Shadcn/ui** para componentes
- **Recharts** para gráficos
- **Lucide React** para ícones

### Backend
- **Flask** (Python)
- **SQLAlchemy** para ORM
- **JWT** para autenticação
- **SQLite** (desenvolvimento) / **PostgreSQL** (produção)

### Funcionalidades Futuras
- Integração com WhatsApp API
- Sistema de SMS
- Envio de e-mails automatizados
- Hospedagem em Heroku

## 🚀 Instalação e Configuração

### Pré-requisitos
- Node.js 18+
- Python 3.8+
- pnpm (recomendado)

### Frontend
```bash
cd aula-management-frontend
pnpm install
pnpm dev
```

### Backend
```bash
cd aula_management_system
pip install -r requirements.txt
python src/main.py
```
